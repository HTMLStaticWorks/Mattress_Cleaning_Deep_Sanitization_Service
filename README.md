# Mattress Cleaning & Deep Sanitization Service — PureSanity

A **completely original, highly polished, premium multi-page website** built following the **"PURE AIR / DEEP CLEAN"** creative direction.

## 🌟 Brand & Design System

- **Primary Color**: `#123B3A` (Deep Forest Teal)
- **Secondary Color**: `#B9D8D1` (Soft Mint)
- **Accent Color**: `#E8A84E` (Warm Hygiene Gold)
- **Typography**:
  - Headings: `DM Serif Display`
  - Body: `Plus Jakarta Sans`
- **Dark Mode**: "Midnight Hygiene" (deep forest teal/charcoal dark theme with mint & gold accents).
- **RTL Support**: Icon toggle with `rtl.css` overrides.

---

## 📄 Included Multi-Page Suite

1. `index.html` - Main Landing Page (Hero, Trust Strip, Visual Services, Mattress Layer Cross-Section Visualizer, 5-Step Process, Before/After Slider, Price Calculator, Pricing Tiers, UV Tech, Why Us, Coverage Map, Reviews, FAQ, Final CTA)
2. `home2.html` - Home Hygiene Journal (Editorial asymmetric layout, science of sleep)
3. `services.html` - Comprehensive Service Catalog (Mattress, Sofa, Pillow, Upholstery, Stain Treatment)
4. `packages.html` - Package Comparison Matrix & Tier Breakdown
5. `about.html` - Story, Equipment Showcase, Technician Standards, Milestones
6. `blog.html` - Home Hygiene Magazine
7. `blog-single.html` - Single Article Detail Template
8. `contact.html` - Home Visit Booking Form & Location Info
9. `login.html` - Customer Login Portal
10. `register.html` - Customer Registration Form
11. `404.html` - Custom Branded Error Page
12. `coming-soon.html` - Fleet Expansion Teaser Page

---

## ⚡ Interactive Features

- **Draggable Before & After Image Comparison Slider** (touch & mouse enabled)
- **Interactive Home Cleaning Price Calculator** (real-time JavaScript dynamic estimator)
- **Mattress Layer Cross-Section Visualizer** (interactive tab switcher revealing fiber layers)
- **Dark Mode & RTL Toggles** (persistent with `localStorage`)
- **Responsive Mobile Navigation Drawer** (slide-in menu at ≤1024px)
- **Home Visit Booking Form** with input validation and non-reloading success modal
